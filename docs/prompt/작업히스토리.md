
작업 프롬프트

나만의 AI 모델을 만들고 싶은데 가능한가?

- 프로젝트 주요기능 : 나만의 AI를 만드로 싶음, 내가 넣은 정보 바탕으로 검색 및 데이터 처리, 나의 작업 현확 파악, 1년간 업무평가용 사용, 이전에 작업 내용에 대하여 검색, 작업 히스토리 파악 등등에 사용예정.
- ollama 이용하여 작은 모델로 사용. (컴퓨터 사양 m1 max 32Gb)
- 지원 언어 한글, 영어
- 파일정보: 이미지, Text파일, md파일, URL link 분석,
- 구분 폴더 회사, 개인, 프로젝트
- 내부 네트워크로 접근하여 사용. (다른컴에서 접속)
- 학습정보는 계속 업데이트 되는 구조. ( 업데이트 쉽게 할수 있는 툴 필요)

----

🎉 프로젝트 완료: 나만의 AI 비서 (My-Brain)

모든 개발 단계가 완료되었습니다. 이제 내부 네트워크의 다른 컴퓨터에서도 접속하여 사용하실 수 있습니다.

🌐 접속 정보
Mac (서버): <http://localhost:3000>
다른 기기 (iPad, 노트북 등): <http://192.168.0.38:3000> (현재 IP 기준)
🚀 실행 방법
터미널 2개를 열어 각각 실행해주세요:

Backend: ./run_server.sh
Frontend: cd apps/web && npm run dev

📂 데이터 관리
파일 추가: data/personal, data/company, data/project 폴더에 파일을 넣으면 자동으로 학습됩니다.
URL 추가: .url 파일을 넣으면 링크 내용을 학습합니다.
업무 기록: 웹의 "Chat" 기능을 통해 기록하거나 API를 연동할 수 있습니다.
📝 확장성 가이드
새로운 기능이나 파일 형식을 추가하고 싶을 때는 architecture.md의 확장성 가이드 섹션을 참고하세요.

수고하셨습니다! 추가적인 도움이 필요하시면 언제든 말씀해 주세요.
