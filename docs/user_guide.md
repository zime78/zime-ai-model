# MyBrianAI 사용자 가이드

이 가이드는 macOS용 **MyBrainAI** 애플리케이션의 설치, 실행 및 데이터 관리 방법을 설명합니다.

## 1. 실행 방법

**MyBrainAI**는 macOS용 애플리케이션 번들(`.app`) 형태로 제공됩니다.

1. `dist` 폴더를 엽니다.
2. `MyBrainAI.app`을 더블 클릭하여 실행합니다.
3. 애플리케이션이 시작되면 자동으로 기본 웹 브라우저가 열립니다.
4. 상단 메뉴바나 Dock 아이콘은 없지만 백그라운드에서 실행됩니다. 종료하려면 **활성 상태 보기(Activity Monitor)**에서 `MyBrainAI`를 강제 종료하거나, 브라우저 창을 닫아도 프로세스는 유지될 수 있으니 주의하세요. (추후 개선 예정)


## 2. 필수 사전 준비 (Ollama)

이 애플리케이션은 로컬 LLM 처리를 위해 **Ollama**가 필요합니다. 바이너리에 포함되어 있지 않으므로 별도 실행이 필요합니다.

1. [Ollama](https://ollama.com/)를 설치합니다.
2. 터미널에서 `ollama serve`를 실행하거나 백그라운드에서 실행 상태인지 확인합니다.
3. 필요한 모델(예: `qwen2.5vl:7b`)이 설치되어 있는지 확인합니다: `ollama list`

## 3. 데이터 추가 및 학습

애플리케이션은 실행 파일과 **동일한 위치**에 있는 `data` 폴더를 감시합니다. 파일을 이 폴더에 넣으면 자동으로 인식하고 학습(인덱싱)합니다.

### 폴더 구조
애플리케이션을 처음 실행하면 자동으로 다음 구조가 생성됩니다:
```
(실행 위치)/
├── MyBrainAI.app  (실행 앱)
└── data/
    ├── company/   (회사 자료)
    ├── personal/  (개인 자료)
    └── project/   (프로젝트 자료)
```

### 지원 파일 형식
다음 확장자를 가진 파일을 위 폴더 중 하나에 넣으세요:
- **텍스트/문서**: `.md`, `.txt`, **(확장자 없음)**
- **이미지**: `.png`, `.jpg`, `.jpeg` (Vision 모델이 설명 생성)
- **웹 페이지**: `.url` (URL 내용을 스크랩)

> [!TIP]
> 파일을 붙여넣기만 하면 자동으로 RAG 엔진에 추가되어 채팅에서 검색할 수 있게 됩니다.
> 
> **데이터 보존 (New):**
> 이제 빌드 시 프로젝트 루트의 `data/` 폴더가 앱 내부로 자동 복사됩니다.
> 따라서 `dist` 폴더를 삭제하고 재빌드해도 데이터가 유지됩니다.
>
> **데이터 새로고침 (Reload):**
> 앱을 재시작하지 않고 데이터를 갱신하려면 다음 API를 호출하세요:
> `curl -X POST http://localhost:8000/api/v1/system/reload`

## 4. 채팅 명령어

My-Brain 채팅에서 사용할 수 있는 특수 명령어:

| 명령어 예시 | 기능 |
|------------|------|
| "도움말", "사용법" | 사용 가이드 표시 |
| "폴더 구조 보여줘" | 학습된 파일의 트리 구조 |
| "폴더 구조 이미지로" | 트리 구조 이미지 생성 |
| "파일 목록", "리스트" | 인덱싱된 파일 목록 |
| 일반 질문 | RAG 검색 후 답변 생성 |

## 5. 환경 설정 (고급)

기본 설정으로 동작하지만, 설정을 변경하고 싶다면 실행 파일 옆에 `.env` 파일을 생성하여 오버라이드할 수 있습니다.

**예시 `.env`:**
```ini
# Ollama 주소 변경 시
OLLAMA_BASE_URL=http://localhost:11434

# 포트 변경 시
API_PORT=8000
```

### API 직접 호출 (개발자용)

| 기능 | 메서드 | URL |
|------|--------|-----|
| AI 채팅 | POST | /api/v1/chat |
| 문서 검색 | POST | /api/v1/search |
| 업무 로그 생성 | POST | /api/v1/work/logs |
| 업무 로그 조회 | GET | /api/v1/work/logs |
| 성과 평가 | GET | /api/v1/work/evaluation/summary |
| 데이터 리로드 | POST | /api/v1/system/reload |

## 6. 트러블슈팅 (문제 해결)

> [!IMPORTANT]
> **오류 로그 확인 (`error.txt`)**:
> 앱 실행 중 문제가 발생하면 실행 파일과 같은 위치에 `error.txt` 파일이 생성됩니다. 이 파일에는 발생한 오류의 상세 내용과 시각이 기록되므로, 문제 해결 시 이 파일을 먼저 확인해주세요.

### Q: "Ollama Server Connection Failed" 경고가 떠요.
**원인**: Ollama가 실행 중이지 않거나 연결할 수 없을 때 발생합니다.
**해결**:
1. 터미널을 열고 `ollama serve`를 입력하여 실행 상태를 확인하세요.
2. `http://localhost:11434`에 접속하여 "Ollama is running" 메시지가 뜨는지 확인하세요.
3. 실행 파일과 같은 위치에 `.env` 파일이 있다면 `OLLAMA_BASE_URL` 설정이 올바른지 확인하세요.

### Q: 실행 후 아무 반응이 없거나 바로 종료돼요.
**원인**: 필수 패키지가 누락되었거나 환경 설정 문제일 수 있습니다.
**해결**:
1. `error.txt` 파일을 확인하여 구체적인 에러 메시지를 확인하세요.
2. "Port already in use" 에러라면 8000번 포트를 다른 프로그램이 사용 중인지 확인하세요.

### Q: 데이터 폴더가 보이지 않아요.
**원인**: 앱이 최초로 실행될 때 폴더를 생성합니다.
**해결**:
1. 앱을 한 번 이상 정상적으로 실행했는지 확인하세요.
2. 실행 파일과 **동일한 위치** (보통 `dist` 폴더 내)에 `data/` 폴더가 생성되었는지 확인하세요.

### Q: `zsh: permission denied: ./MyBrainAI.app` 에러가 떠요.
**원인**: `.app`은 파일이 아니라 폴더입니다.
**해결**: 
1. `open dist/MyBrainAI.app` 명령어를 사용하세요.
2. 만약 실행이 안된다면 `scripts/build_mac.sh`로 재빌드 후 시도하세요. (메타데이터 자동 수정됨)
